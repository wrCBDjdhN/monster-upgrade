# 打怪升级 怪物增强与平衡性重构设计文档

**日期：** 2026-08-26
**版本：** v1.0
**状态：** 待批准
**目标：** 增强怪物和BOSS，平衡武器和装备，创建可扩展的系统

---

## 一、设计目标

### 1.1 核心目标（全部兼顾）
- ✅ 增强挑战性 - 让游戏更有威胁
- ✅ 改善新手体验 - 降低早期难度
- ✅ 丰富战术选择 - 不同武器/装备组合都有用武之地
- ✅ 修正不平衡 - 解决已知的平衡问题

### 1.2 怪物增强方向
- ✅ 行为多样化 - 新的攻击模式、特殊技能或AI行为
- ✅ 生态系统增强 - 不同怪物之间有协同效应，BOSS战有阶段性变化
- ✅ 特色化设计 - 每个怪物都有独特的机制和弱点

### 1.3 武器装备平衡
- ✅ 差异化定位 - 每种武器/装备有明确的优缺点，适合不同战斗风格

### 1.4 难度曲线
- ✅ 波浪式难度 - 有难有易的节奏变化，BOSS战是高潮
- ✅ 区域化难度 - 不同地图区域有不同难度等级

### 1.5 实施策略
- ✅ 一次性全面调整 - 同时修改所有怪物、BOSS、武器和装备
- ✅ 可扩展系统设计 - 方便未来添加新内容

## 二、当前平衡状态分析

### 2.1 严重Bug（必须修复）

**Bug 1：土匪成群刷新失效**
- 位置：`game/respawn.py:207`
- 问题：`view.monsters.append(m)` 应为 `view.monsters.append(bm)`
- 影响：额外土匪bm从未加入怪物列表，主土匪m被同一引用追加3-5次
- 后果：土匪群实际只有1只且行为异常（移动/攻击翻倍）

**Bug 2：主题装备等级未生效**
- 位置：`game/respawn.py:209-210`
- 问题：respawn用兜底`MONSTER_GEAR_LEVEL_RANGE (1,10)`而非主题`gear_level`
- 影响：space怪护甲等级应为10-50，实际只有1-10
- 后果：space怪效果等级只有Lv1-2而非Lv3-5

## 三、设计方案：系统重构方案

### 3.1 Bug修复（优先级最高）

**修复1：土匪成群刷新**
```python
# game/respawn.py:207
# 修改前：
view.monsters.append(m)
# 修改后：
view.monsters.append(bm)
```

**修复2：主题装备等级生效**
```python
# game/respawn.py:209-210
# 修改前：
assign_monster_armor(m, level=random.randint(*MONSTER_GEAR_LEVEL_RANGE), theme=theme)
assign_monster_helmet(m, level=random.randint(*MONSTER_GEAR_LEVEL_RANGE), theme=theme)

# 修改后：
from config import MONSTER_THEME_EQUIP
gear_level = MONSTER_THEME_EQUIP[theme]["gear_level"]
assign_monster_armor(m, level=random.randint(*gear_level), theme=theme)
assign_monster_helmet(m, level=random.randint(*gear_level), theme=theme)
```
